# ADR-002: Serial Communication Between Arduino Uno and ESP32

## Status
Accepted

## Context
The Greenhouse Care System uses an Arduino Uno to collect sensor readings and handle local hardware control. An ESP32 receives these readings and sends them to the backend through Wi-Fi.

The two boards need a communication method to exchange sensor data reliably.

## Decision
Use serial communication between the Arduino Uno and ESP32.

- Arduino Uno digital pin D11 sends sensor data.
- A 1kΩ and 2kΩ resistor voltage divider is used on the signal line to reduce the Arduino's 5V logic signal to a safer level for the ESP32.
- The voltage divider junction connects to ESP32 GPIO16, labeled D16 on the board.
- Both boards share a common ground (GND).

## Alternatives Considered
1. Use a wireless connection between the two boards.
2. Use a different communication interface, such as I²C.
3. Use a wired serial connection with a voltage divider.

## Consequences

### Benefits
- Provides a simple wired connection for transferring sensor readings.
- Allows the ESP32 to forward readings to the backend.
- Uses the existing hardware and wiring.

### Trade-offs
- Requires additional wiring and a resistor voltage divider.
- Both boards must use compatible serial settings and data formats.
- Incorrect wiring or serial configuration can prevent communication.
