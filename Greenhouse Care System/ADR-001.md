# ADR-001: Using Arduino Uno and ESP32 Together

## Status
Accepted

## Context
The Greenhouse Care System needs to monitor environmental conditions, control connected hardware, and send sensor readings to a dashboard. The project uses an Arduino Uno and an ESP32 to handle these requirements.

## Decision
Use both the Arduino Uno and ESP32 in the system.

- The Arduino Uno handles sensor readings and local hardware control.
- The ESP32 handles Wi-Fi communication and sends readings to the backend.
- The two boards communicate through serial communication.

## Alternatives Considered
1. Use only an Arduino Uno, which would require additional hardware for Wi-Fi connectivity.
2. Use only an ESP32, which could combine sensor control and Wi-Fi communication on one board.
3. Use both boards to separate local hardware control from network communication.

## Consequences

### Benefits
- Separates hardware control from network communication.
- Allows the Arduino to continue local control independently of dashboard connectivity.
- Uses the project's existing hardware.

### Trade-offs
- Requires communication wiring between the boards.
- Requires compatible voltage levels for serial communication.
- Adds complexity compared with using only one board.
